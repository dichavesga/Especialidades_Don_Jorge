Sobre este proyecto

Acerca del sitio

Este sitio web fue desarrollado como proyecto académico del curso ISW-512 Diseño de Aplicaciones Web, de la carrera Ingeniería del Software de la Universidad Técnica Nacional.

Propósito

Una vitrina digital para un negocio familiar

El objetivo del proyecto es dotar a Especialidades Don Jorge —una empresa familiar dedicada a la producción y venta de embutidos artesanales en Santa Gertrudis Sur de Grecia— de una presencia web propia, responsiva y de fácil navegación, que le permita mostrar su catálogo de productos y facilitar el contacto directo con sus clientes.

El sitio está construido bajo la modalidad Mobile First, de manera que la experiencia se adapta correctamente desde teléfonos móviles hasta pantallas de escritorio.

Tecnologías

Con qué está construido

HTML5

Estructura semántica de todas las páginas, además de los elementos multimedia nativos de audio y video.

CSS3

Hoja de estilos externa con variables de color, tipografía personalizada y diseño responsivo mediante media queries.

JavaScript

Validaciones del formulario, cálculo de edad, controles de video, filtros y lightbox de la galería.

jQuery

Manipulación del DOM, generación dinámica de tarjetas y consumo de los archivos JSON mediante $.getJSON().

Bootstrap 5

Framework responsivo utilizado principalmente para el componente Carousel de la página principal.

APIs

Google Maps API para la geolocalización y el trazado de rutas, y Open-Meteo API como servicio REST externo.

Datos dinámicos

Contenido cargado por JSON

El catálogo de productos y la galería de imágenes no están escritos directamente en el HTML: se exponen en archivos JSON publicados en el mismo sitio (data/productos.json y data/galeria.json) y se consumen como un API Rest, de forma que el contenido se carga dinámicamente.

Créditos

Contenido y recursos

El logotipo y la información comercial fueron proporcionados por el cliente. La iconografía del sitio fue elaborada en SVG para este proyecto. No se utilizaron plantillas de terceros: el diseño y la maquetación son originales.
