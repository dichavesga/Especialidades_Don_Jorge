Sobre el desarrollo

Aspectos destacados del proyecto

Diseño original

Toda la línea gráfica —paleta de colores, tipografía e iconografía SVG— fue creada específicamente para este cliente, sin uso de plantillas de terceros.

Mobile First

La maquetación parte del diseño móvil y escala progresivamente hacia tablet y escritorio mediante media queries.

Contenido dinámico

Productos y galería se sirven desde archivos JSON propios y se consumen como API Rest, permitiendo actualizar el contenido sin tocar el HTML.

Trabajo con cliente real

El proyecto se desarrolló levantando requerimientos directamente con el dueño del negocio e incorporando su retroalimentación en cada iteración.
